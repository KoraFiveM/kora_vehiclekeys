# API reference

The resource exposes server exports under its own name and the stock `qb-vehiclekeys` name, three client exports for the stock name, and the shared `Config` table. Net events and callbacks are in [Events and callbacks](../events.md).

| Module | Namespace | Realms |
| --- | --- | --- |
| [Server exports](./server-exports.md) | `exports.kora_vehiclekeys · exports['qb-vehiclekeys']` | server |
| [Client exports](./client-exports.md) | `exports['qb-vehiclekeys']` | client |
| [Configuration](./configuration.md) | `Config` | shared |
